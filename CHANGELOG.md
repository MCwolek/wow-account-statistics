# Changelog

## 1.0.0

First release.

- Statistics window with every Statistic of the game's Statistics panel by Category, the chosen character's value and the Account Total.
- Account Totals across all your characters: sums, or the highest value for records such as "Largest hit dealt". Hover a total for the top 5 characters behind it.
- Search box that narrows the list to matching Statistics and Categories.
- Character dropdown showing when each character last synced; forget a character with the X on its entry.
- Minimap button that opens the window and can be dragged around the Minimap; `/stats minimap` hides or shows it.
- English and German text, following the game's language.
